# 实验7 运行说明：验收标准与测试样例生成

本目录对应实验7“个人软件核心AI能力原型设计与开发”。原型已集成进 AI 需求歧义审查器，作为“验收标准”页面和 `/api/acceptance` 接口使用。

## 1. 环境

- JDK 17、Maven 3.9+（或 `backend/run-local.ps1` 自动查找 Maven）
- Node.js 20+
- 千问 API Key：写入 `backend/.env.local`（已在 .gitignore 排除）

```dotenv
AI_MODE=qwen
DASHSCOPE_API_KEY=你的Key
QWEN_MODEL=qwen-plus
```

## 2. 启动

```powershell
cd backend
.\run-local.ps1          # 端口 8080

cd frontend
npm run dev              # 端口 5173
```

打开 http://localhost:5173，左侧「验收标准」。页面输入需求（≤3000 字）或点示例，选择生成方案后点“生成验收标准”。

## 3. 接口

```http
POST /api/acceptance/runs
{"text":"需求原文","promptVersion":"revised","mode":"model"}
```

- `mode=model`：调用模型；`mode=rule`：无 AI 模板基线（用于对比，不用于日常）。
- `promptVersion=revised`：修订版（程序检查 + 修复）；`original`：初版（单次调用，复现 v1 行为）。
- 返回：`runId`、`status`、`promptVersion`、`model`、`durationMs`、`usage`、`report`、`checks`、`attempts`、`error`。
- 状态：`SUCCESS`、`REFUSED`（超范围）、`CHECK_FAILED`（修复用尽）、`FAILED`（模型/解析失败）。
- 日志：`backend/logs/acceptance-runs/<runId>.jsonl`（逐事件）与 `<runId>.json`（完整产物）。

## 4. 评测

```powershell
cd experiments/exp7
python run_eval.py --label rule --mode rule --version revised
python run_eval.py --label v1 --mode model --version original
python run_eval.py --label v2 --mode model --version revised
```

结果在 `experiments/exp7/results/<label>/`：`results.json`、`summary.md`、`raw/<样例编号>.json`。人工判断在 `judgments.json`，用 `--recheck` 可在不调用模型的情况下按当前规则重算。

