# 实验6 运行说明：审查档案分析 Agent

本目录对应实验6“工具调用、Agent 与 Harness 实现”。Agent 已集成进 AI 需求歧义审查器，
作为“档案分析”页面和 `/api/agent` 接口提供。

## 1. 环境

- JDK 17、Maven 3.9+（或 `backend/run-local.ps1` 自动寻找本机 Maven）
- Node.js 20+（前端）
- 千问 API Key：写入 `backend/.env.local`（该文件已被 .gitignore 排除）

```dotenv
AI_MODE=qwen
DASHSCOPE_API_KEY=你的Key
QWEN_MODEL=qwen-plus
```

Agent 必须使用真实模型，不能用 Mock；未配置 Key 时接口返回“模型调用失败”。

## 2. 启动

```powershell
# 后端（读取 .env.local，端口 8080）
cd backend
.\run-local.ps1

# 前端（端口 5173）
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，左侧“档案分析”。

可选配置（`backend/src/main/resources/application.yml` 或环境变量）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `AGENT_MAX_STEPS` | 6 | 最大执行步数（一步 = 一次模型响应） |
| `AGENT_TOTAL_TIMEOUT_MS` | 60000 | 单次运行总时限 |
| `AGENT_MODEL_TIMEOUT_MS` | 30000 | 单次模型调用超时 |
| `AGENT_TOOL_TIMEOUT_MS` | 5000 | 单次工具执行超时 |
| `AGENT_MAX_ANSWER_RETRIES` | 2 | 结果校验不通过后的重答次数 |
| `AGENT_CONFIRM_TTL_MS` | 300000 | 等待人工确认的有效期 |
| `AGENT_LOG_DIR` | `./logs/agent-runs` | 运行日志目录 |

## 3. 接口

```http
POST /api/agent/runs
{"question": "现在有多少份档案，风险分布如何？"}

POST /api/agent/runs/{taskId}/confirm
{"approved": true}
```

返回字段：`taskId`、`status`（SUCCESS / NEED_CONFIRM / DENIED / STEP_LIMIT / TIMEOUT / CHECK_FAILED / FAILED）、
`answer`、`steps[]`（工具轨迹）、`confirm`（待确认操作）。

## 4. 工具与边界

| 工具 | 类型 | 说明 |
|---|---|---|
| `list_reviews` | 只读 | 列出档案摘要，limit 1–20 |
| `compute_risk_stats` | 只读 | 统计总数与高/中/低风险、问题类型分布 |
| `get_review_detail` | 只读 | 按 UUID 读取档案明细 |
| `search_knowledge` | 只读 | 检索知识库，q 2–100 字符，k 1–5 |
| `delete_review` | 写操作 | 删除档案，**必须人工确认** |

模型只能给出工具名和参数；工具名白名单、参数校验、步数/超时、确认流程、结果数字校验全部由程序执行。
