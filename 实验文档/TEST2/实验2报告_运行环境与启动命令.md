## 2. 前端启动命令

在 PowerShell 中执行：

```powershell
cd "D:\deepseek harness workspace\AI_Request_check\frontend"
npm run dev
```

默认运行地址通常为：

```text
http://localhost:5173/
```

如果端口被占用，Vite 会在终端输出新的端口，例如 `http://localhost:5174/`，报告中应以你实际终端显示的地址为准。

建议截图：

- 前端终端启动成功截图，包含 `npm run dev` 和 Local 地址。
- 浏览器打开前端页面截图，能看到“需求歧义审查器”页面。

## 3. 后端启动命令

在另一个 PowerShell 窗口中执行：

```powershell
cd "D:\deepseek harness workspace\AI_Request_check\backend"
.\run-local.ps1
```

默认运行地址为：

```text
http://localhost:8080
```

API 前缀为：

```text
http://localhost:8080/api
```

可用于验证后端是否启动的接口：

```text
http://localhost:8080/api/reviews
```

如果浏览器访问该地址返回 `[]` 或历史记录 JSON，说明后端接口已响应；如果返回错误，请以终端日志为准排查。

建议截图：

- 后端终端启动成功截图，包含 Spring Boot 启动日志和端口 `8080`。
- 浏览器访问 `http://localhost:8080/api/reviews` 的结果截图。
